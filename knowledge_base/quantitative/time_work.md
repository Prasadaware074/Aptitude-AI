# Quantitative Aptitude: Time and Work

## Overview
Time and Work problems test the inverse relationship between the number of workers, rate of work, and total time required to complete a job.

## Formulas
1. If A completes a work in `x` days, A's 1-day work = `1 / x`.
2. Total Work = `Efficiency * Time`.
3. Combined 1-day work of A and B = `1/x + 1/y = (x + y) / (x * y)`.
4. Combined time taken = `(x * y) / (x + y)` days.
5. **Chain Rule**: `(M1 * D1 * H1) / W1 = (M2 * D2 * H2) / W2` where M=Men, D=Days, H=Hours/day, W=Work done.

## Worked Example
- A takes 12 days, B takes 24 days.
- Combined time = `(12 * 24) / (12 + 24) = 288 / 36 = 8` days.
