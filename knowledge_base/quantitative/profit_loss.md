# Quantitative Aptitude: Profit and Loss

## Overview
Profit and Loss is a fundamental section in commercial arithmetic. It evaluates financial transactions involving Cost Price (CP), Selling Price (SP), Marked Price (MP), Profit, Loss, and Discounts.

## Core Definitions
- **Cost Price (CP)**: The price at which an item is purchased.
- **Selling Price (SP)**: The price at which an item is sold.
- **Profit / Gain**: Occurs when `SP > CP`. `Profit = SP - CP`.
- **Loss**: Occurs when `CP > SP`. `Loss = CP - SP`.
- **Marked Price (MP)**: The price tag list price on an item before discount.

## Core Formulas
1. `Profit % = (Profit / CP) * 100`
2. `Loss % = (Loss / CP) * 100`
3. `SP = CP * (100 + Profit %) / 100` (for profit)
4. `SP = CP * (100 - Loss %) / 100` (for loss)
5. `CP = (SP * 100) / (100 + Profit %)`
6. `Discount = MP - SP`
7. `Discount % = (Discount / MP) * 100`

## Shortcuts & Dishonest Dealer Concepts
- **Dishonest Merchant**: If a trader uses false weight of `g` grams instead of actual `W` grams:
  - `Gain % = [ Error / (True Value - Error) ] * 100`
- **Equal SP with Same % Profit and Loss**: If two items are sold at the same SP, one at `x%` profit and the other at `x%` loss, there is an overall loss of `(x / 10)^2 %`.

## Worked Examples
- **Example 1**: A shopkeeper sells an item for $240 at 20% profit. Find Cost Price.
  - *Solution*: CP = (240 * 100) / (100 + 20) = 24000 / 120 = $200.
