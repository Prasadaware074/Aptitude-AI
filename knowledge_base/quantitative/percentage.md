# Quantitative Aptitude: Percentage

## Overview
Percentage means 'per hundred'. It is a way of expressing a number as a fraction of 100. It is widely used in aptitude exams for calculating growth rates, discounts, interest, and data interpretation.

## Definitions
- **Percentage**: A ratio where the second term is always 100. Symbol: `%`.
- **Base Value**: The original number on which the percentage is calculated.

## Core Formulas
1. `Percentage = (Part / Whole) * 100`
2. `Part = (Percentage / 100) * Base`
3. `Percentage Increase = (Increase in Value / Original Value) * 100`
4. `Percentage Decrease = (Decrease in Value / Original Value) * 100`
5. `Consumption Reduction % = [r / (100 + r)] * 100` (when price increases by r%)
6. `Consumption Increase % = [r / (100 - r)] * 100` (when price decreases by r%)

## Important Shortcuts
- **Successive Percentage Change**: If a value changes by `a%` and then by `b%`, Net % Change = `a + b + (a * b) / 100`.
- **Fraction Equivalents**:
  - `1/2 = 50%`
  - `1/3 = 33.33%`
  - `1/4 = 25%`
  - `1/5 = 20%`
  - `1/6 = 16.67%`
  - `1/8 = 12.5%`

## Worked Examples
- **Example 1**: If the price of petrol increases by 25%, by how much should consumption be reduced so that expenditure remains unchanged?
  - *Solution*: Reduction % = [25 / (100 + 25)] * 100 = 25/125 * 100 = 20%.

## Common Mistakes
- Calculating percentage change using the new value instead of the original value as base denominator.
- Adding consecutive percentage changes directly instead of using the successive change formula.
